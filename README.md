# Hierarchical Dimensions of Psychiatric Comorbidity

This repository contains the full Python analysis pipeline:

**"Hierarchical Dimensions of Psychiatric Comorbidity: An Integrated Latent Class–Network Analysis of U.S. Mental Health Client-Level Data (MHCLD 2021)"**  
Author: Mounika Supriya Bommi

## 🧪 Project Overview

This project introduces a scalable analytic framework that integrates:
- **Latent Class Analysis (LCA)** to identify subgroups based on diagnostic profiles
- **Network analysis** to model inter-disorder relationships
- **DSM-5 mapping** to assess convergence with nosological systems

The analysis was applied to the 2021 U.S. Mental Health Client-Level Dataset (MHCLD) comprising over 100,000 treatment-seeking individuals.
